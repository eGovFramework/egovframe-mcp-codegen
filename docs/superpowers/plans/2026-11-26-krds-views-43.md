# 4.3 Boot / 4.3 WAR 화면 KRDS 전환 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `egov_scaffold_project` / `egov_add_entity` / `egov_add_query_view` 가 만드는 4.3 Boot·4.3 WAR 화면을 5.1 Boot 와 같은 KRDS 마크업·정적 자산·flatpickr 달력·KRDS 페이지네이션으로 바꾼다. 컨트롤러·URL·검증 방식은 스택별로 유지한다.

**Architecture:** 스택 매트릭스의 `staticAssets` 를 세 스택 모두 `static50` 으로 통일하고, rte 4.3.2 에 없는 KRDS 페이지네이션 렌더러를 4.3 Boot·WAR 각각에 자족적 Java 클래스로 추가한다. 뷰 템플릿(Thymeleaf 5종, JSP 4종)은 `templates/boot50/thymeleaf/*` 를 기준으로 KRDS 마크업으로 다시 쓰되 각 스택의 JS 함수·URL·폼 태그는 그대로 둔다. TypeScript 로직은 바꾸지 않는다 (템플릿·매니페스트·stacks.json·테스트만).

**Tech Stack:** TypeScript/vitest (생성기), Handlebars 템플릿, 산출물은 Java 8 + Spring Boot 2.7.18/Thymeleaf 3.0 (Boot 4.3) 과 Spring 5.3 + JSP/JSTL (WAR 4.3), rte 4.3.2, KRDS 정적 자산(`templates/static50/`), flatpickr 4.6.13(CDN).

**Spec:** `docs/superpowers/specs/2026-11-26-krds-views-43-design.md`
