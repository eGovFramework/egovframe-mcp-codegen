# v5.1.0 Beta 릴리스 노트

- 배포일: 2026-11-27
- 패키지 버전: 5.1.0

DDL 을 바탕으로 표준프레임워크 프로젝트와 CRUD 코드를 생성하는 MCP 서버, eGovFrame Codegen(코드생성 MCP)의 최초 배포 버전입니다.

## 주요 내용

- 제공 도구 4개
  - `egov_scaffold_project`: DDL 로 표준프레임워크 프로젝트를 새로 생성합니다.
  - `egov_add_entity`: 기존 프로젝트에 새 엔티티의 CRUD 코드를 추가합니다.
  - `egov_add_query_view`: 다중 JOIN `SELECT` 문으로 조회 전용 리포트 화면을 추가합니다.
  - `egov_add_attach_file_infrastructure`: Boot 프로젝트에 표준 첨부파일 인프라를 설치합니다.
- 3개 스택 지원
  - 5.1 Boot: 실행환경 5.1.0, Java 17, Spring Boot 3, Thymeleaf
  - 4.3 Boot: 실행환경 4.3.2, Java 8, Spring Boot 2.7, Thymeleaf
  - 4.3 WAR: 실행환경 4.3.2, Java 8, Spring 5.3, JSP + Tomcat
- 생성 항목: Controller, Service, ServiceImpl, MyBatis Mapper, VO, KRDS 화면과 페이징, 검색, 유효성 검증, 예외 처리 코드를 생성합니다.
- 보안 설정: 5.1 Boot 프로젝트에는 Spring Security 보안 설정(보안 응답 헤더, CSRF 보호, StrictHttpFirewall, CORS)이 기본으로 들어갑니다.
- 사용자 확인: 스택이나 첨부파일 포함 여부를 지정하지 않으면 서버가 MCP Elicitation 으로 사용자에게 직접 묻습니다.
- 덮어쓰기 없음: `egov_add_entity` 는 생성할 파일 가운데 하나라도 이미 있으면 생성 전체를 거부합니다. 생성할 파일이 모두 같은 내용으로 이미 있을 때에는 변경 없이 성공으로 응답합니다.
- 화면 라벨: 컬럼과 테이블의 COMMENT 를 화면 라벨로 사용합니다.
- 마이그레이션 SQL: 7개 DBMS(Oracle, Tibero, Altibase, CUBRID, Goldilocks, MySQL, PostgreSQL)용 SQL 을 함께 생성합니다. MySQL 용 SQL 은 MariaDB 에도 그대로 사용합니다.
- 즉시 실행: 생성된 프로젝트는 내장 HSQLDB 로 바로 실행할 수 있습니다.
- 결정적 생성: 모든 코드는 표준프레임워크 템플릿에서 만들어지므로, 같은 DDL 은 항상 같은 코드를 생성합니다.
- 오프라인 동작: 실행에 필요한 의존 패키지가 tgz 에 함께 들어 있어서 폐쇄망에서도 설치하고 실행할 수 있습니다.

## 요구 사항

- Node.js 18 이상 (Node.js 22 권장)
- 생성된 프로젝트를 빌드하고 실행하려면 JDK 와 Maven 이 필요합니다. 5.1 Boot 는 JDK 17, 4.3 Boot 와 4.3 WAR 는 JDK 8 을 기준으로 합니다.

## 배포 파일

배포 파일은 [표준프레임워크 포털](https://www.egovframe.go.kr/home/sub.do?menuNo=114)에서 내려받습니다. 실행에 필요한 의존 패키지가 모두 순수 JavaScript 이므로, 하나의 파일을 Windows, macOS, Linux 에서 공통으로 사용합니다.

| 운영체제 | 파일 |
|----------|------|
| 모든 운영체제 공통 | `egovframe-mcp-codegen-5.1.0.tgz` |

### 체크섬

| 파일 | MD5 | SHA256 |
|------|-----|--------|
| `egovframe-mcp-codegen-5.1.0.tgz` | `c1d751dedd876c60cfed17ec0efde545` | `6bb207c5de76125a0deb72459c4bac39e32bd2b3c5fe33595fb2fb855f064b4e` |

내려받은 파일의 체크섬은 다음 명령으로 확인합니다.

```bash
shasum -a 256 egovframe-mcp-codegen-5.1.0.tgz    # macOS, Linux
```

```bat
certutil -hashfile egovframe-mcp-codegen-5.1.0.tgz SHA256
```

## 설치와 등록

배포 파일은 압축을 풀지 않고 `npx` 로 실행하도록 AI 클라이언트에 등록합니다. 클라이언트별 등록 방법은 [설치와 MCP 클라이언트 등록 가이드](../setup/MCP_SETUP_GUIDE.md)에 있습니다.

```bash
npx -y --package=<tgz 파일의 절대 경로> egovframe-mcp-codegen
```
